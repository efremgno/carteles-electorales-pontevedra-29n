# Carteles electorales 29-N · Provincia de Pontevedra

Mapa interactivo de los lugares habilitados para la colocación gratuita de carteles electorales en los 61 concellos de la provincia de Pontevedra, para las elecciones generales del 29 de noviembre de 2026.

**Ver el mapa:** https://efremgno.github.io/carteles-electorales-pontevedra-29n/

## Fuente

Edictos de las Xuntas Electorais de Zona (Vigo, Pontevedra, Cambados, Tui, Ponteareas, Lalín y A Estrada) publicados en el [BOPPO nº 202, de 20 de octubre de 2026](https://boppo.depo.gal/detalle/-/boppo/2026/10/20).

## Contenido

| Archivo | Qué es |
| --- | --- |
| `index.html` | El mapa (un solo archivo con los datos dentro) |
| `data/carteles_pontevedra_29N.csv` | Tabla completa: 249 lugares de carteles y las bandeirolas por concello |
| `data/carteles_pontevedra_29N.geojson` | Los 249 puntos con coordenadas |
| `data/carteles_pontevedra_29N.kml` | Los mismos puntos, para Google My Maps o Google Earth |

## Precisión de las ubicaciones

Las coordenadas se obtuvieron con OpenStreetMap (Nominatim) a partir del texto de los edictos.

- **Exacta** (rojo, 162 puntos): el lugar se encontró en OpenStreetMap.
- **Aproximada** (ámbar, 87 puntos): no se encontró con el nombre del edicto; el punto marca el centro del concello o la parroquia y conviene comprobarlo sobre el terreno.

Meis, Ponte Caldelas y Soutomaior no aparecen con puntos: sus edictos solo recogen postes para bandeirolas.
